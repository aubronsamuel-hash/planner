# Planner Monorepo – Phase 1 Codex Init

Phase 1 establishes the foundational scaffolding for the Planner platform. The
repository now mirrors the documented blueprint with backend, frontend,
infrastructure, tests, and CI placeholders.

## Quickstart
1. `make bootstrap`
2. `make up`
3. Visit `http://localhost:5173` for the frontend placeholder.
4. Query `http://localhost:8000/api/v1/health` for the backend health check.

Refer to `docs/INDEX_v3.md` and `codex_roadmap_v4.md` for the full delivery
context.
