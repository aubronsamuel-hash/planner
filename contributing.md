# Contributing to Planner

Thank you for helping bootstrap the Planner monorepo. During Phase 1 Codex Init
we focus on scaffolding and documentation alignment.

## Getting Started
1. Clone the repository.
2. Run `make bootstrap` to copy environment templates.
3. Use `make up` to launch the local stack once dependencies are installed.

## Commit Guidelines
- Use Conventional Commits (`type(scope): message`).
- Keep pull requests focused and reference roadmap items where possible.

## Code Quality
- Run `make lint` and `make test` locally before opening a PR.
- Ensure new folders mirror the structure described in `/docs/blueprint`.

## Communication
Open a discussion in GitHub if you need clarifications on roadmap priorities or
observability requirements.
